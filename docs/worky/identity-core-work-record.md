## Frozen core contracts

- Identity extends Value; immutable final application fields and props define
  equality, preserving runtime identity kind and scope.
- UuidValue extends Identity, retaining generate/fromString validation.
- Entity<I> and AggregateRoot<I> require id; UuidEntity/UuidAggregateRoot provide
  optional generated UUID convenience with no unchecked generic cast.
- Repository<T extends AggregateRoot<I>, I extends Identity> accepts I for
  lookup/deletion and T for save. InMemoryRepository uses Map<I, T>.
- DomainEvent<I> preserves I in aggregateId and UuidValue in eventId.
- Aggregate event collection is typed by I. EventBus carries heterogeneous
  DomainEvent<Identity> values and retains concrete subscription types.

Timestamps, touch, upsert/delete semantics, fake storage isolation/enumeration
and event occurrence equality are not redesigned. All owned UUID tests and
examples migrate to the explicit stock path and linked repository generics.
