# Public API and quickstart readiness (#102)

This integration branch implements #103–#107 in dependency order, starting from
main after #122. Version 1.0 is the first compatibility baseline. Authentication
remains optional, and release/publication work under #30 remains separate.

The child changes cover supported exports, serializer contracts, complete
quickstarts, capability documentation, and an executable documentation gate.
Each child is tested before its PR is merged into this branch. The parent PR
remains unmerged for review.

## #103 — supported exports

Removed the unused GraphTraverser, split SQL analyzer/schema generation into
`dddart_repository_sql/generator.dart`, and exposed only SQLite's builder
factory through `builder.dart`. Runtime imports keep runtime extension contracts.
`docs/PUBLIC_API.md` inventories every entrypoint and export, including intentional
SDK re-exports and generated-code support helpers.

Validation on Dart 3.13.7: SQL and SQLite package gates passed in CI mode
(SQLite: 127 tests); MySQL passed in local mode, including external regeneration
and custom-base compilation. MySQL service-dependent tests were not run for this
build-time export change. SQLite's external consumer also rejects five hidden
symbols through runtime imports and accepts the supported generator entrypoint.
