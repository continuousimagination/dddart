# DDDart

DDDart is a toolkit for building Dart applications around domain models. Keep
business rules in entities and value objects, then connect them to persistence,
HTTP, or events through typed contracts. Add the packages and adapters your
application needs.

- [Build your first model](docs/quickstarts/core/README.md): run an order example
  that saves an aggregate and reacts to a domain event.
- [Find a runnable example](docs/QUICKSTARTS.md): generated JSON, database
  repositories, a public HTTP API, and more.
- [Choose packages](docs/CAPABILITIES.md): what each package does and where it runs.
- [Browse the guides](docs/README.md) or read the
  [online documentation](https://continuousimagination.github.io/dddart/).

For changes to the project, see [development and validation](scripts/README.md).
